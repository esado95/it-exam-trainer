# IT Atelier

Французский IT-тренажёр по трём предоставленным fiches: SYS, NET, SEC. Учебный корпус полностью прочитан; реестр содержит 27 тематических блоков. Это не официальный référentiel и не модель реального экзамена.

## Возможности

- Диагностика: 12 вопросов, по четыре на направление, по одному за раз.
- Квиз: точная проверка выбора, разбор по-русски и короткий французский ответ. Формат без обоснования, корректность выбора оценивается /20.
- Практика и жюри: открытые ситуации. Жюри включает основной вопрос и два уточнения перед разбором.
- Свободные ответы оцениваются по содержанию в чате: кнопка создаёт запрос со всей попыткой и критериями. JSON оценки можно вернуть в приложение. Вопросы и решения не оцениваются поиском ключевых слов.
- Уверенность 0–100%, постепенные подсказки, отдельный учёт самостоятельных и assisted результатов, журнал попыток, реестр навыков, экспорт/импорт.
- Браузерное сохранение прогресса, тёмное оформление, адаптация к телефону, клавиатурная навигация.

По каждой узкой теме банк ограничен; если запрошено больше вопросов, приложение сообщает доступное количество и не создаёт скрытые дубликаты. Адаптивный квиз распределяет слабые темы, повторение и непроверенное примерно 50/30/20, когда банк и профиль это позволяют. Статус «устойчиво отвечаю» требует нескольких ответов, разных вопросов и навыков.

Приложение не содержит ключей API и не отправляет ответы на сервер. Исходные Word-файлы, их полные тексты и личные журналы не включены в публикацию. На GitHub размещены приложение и созданные учебные задания с указанием источников. Экспортированные ответы и прогресс остаются у пользователя.

## Запуск и тесты

Нужен любой статический HTTP-сервер. Все пути относительные, поэтому сайт работает в подпапке GitHub Pages.

```sh
python -m http.server 8000
node --test tests/engine.test.mjs
```

Браузерные проверки описаны в TEST-REPORT.md. JSON прогресса — пользовательские локальные данные, не доказательство результатов независимого экзамена.
